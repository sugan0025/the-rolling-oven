# Git Workflow Rules

1. **NEVER push directly to the `main` or `master` branch.**
2. When a new change is requested, always create a new feature branch (e.g., `git checkout -b feature/name-of-feature`).
3. Make changes and test them locally.
4. **ONLY** push the branch to the remote repository when the user explicitly says "push". Do not push automatically without permission.
